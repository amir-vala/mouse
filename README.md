# Git Tree Explorer

اپلیکیشن شامل یک بک‌اند پایتونی و فرانت‌اند جاوااسکریپتی است که یک مسیر مشخص را اسکن می‌کند، ریپوهای گیت را پیدا می‌کند و تاریخچه‌ی کامیت‌ها را به صورت نمودار درختی نمایش می‌دهد. برای هر پروژه یک نمودار جداگانه تولید می‌شود و با حرکت موس روی هر گره، جزئیات کامیت در یک تولتیپ شناور نمایش داده می‌شود.

## اجرا

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

سپس مرورگر را روی آدرس `http://localhost:5000` باز کنید.

## پیکربندی

- مسیر اسکن پیش‌فرض از متغیر محیطی `GIT_SCAN_ROOT` خوانده می‌شود.
- همچنین می‌توانید مسیر را در فرم بالای صفحه وارد و اسکن را اجرا کنید.

## نکات

- برای جلوگیری از بار اضافه، حداکثر ۲۵۰ کامیت اخیر هر ریپو خوانده می‌شود.
- لینک‌های ادغام (merge) با خط‌های خط‌چین نمایش داده می‌شوند.
